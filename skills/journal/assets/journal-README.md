# Personal journal

Cross-project notes on how I work with my coding agent. Distinct from auto-memory (which holds atomic action-shaping rules) — this is narrative, append-only, mine to curate.

## Folders

- `reflections/` — one file per notable session (`YYYY-MM-DD-slug.md`). Append-only. Skip routine sessions; only write when there was a notable preference, redirection, or friction point.
- `distilled/` — synthesised summaries built from reflections. Short, prompt-ready, safe to paste into a new session or load via a hook.

## Trigger

Say "wrap up", or invoke the `journal` skill directly. The agent drafts a reflection following the template below and shows it in chat; I edit before it's saved.

## Reflection template

```markdown
# YYYY-MM-DD — <short subject>

## Subject
One line: what we were doing.

## How I iterated
- Started with: …
- Narrowed by: …
- Locked in via: structured questions / direct feedback / silent approval

## Reactions
- Liked: …
- Pushed back on: …
- Silently accepted: …

## Keep doing
- …

## Change
- …

## Open threads
- …
```

## Rule for entries

Capture **what surprised either of us**, not a blow-by-blow recap. If nothing surprised anyone, don't write.

## Privacy

Reflections accumulate candid notes about real work, real decisions, and sometimes real colleagues. Keep this directory out of any repository you publish — the skill is shareable, the journal is not.
